Создать Chrome Plugin для Gitlab Pipelines

## Часть 1

Chrome Plugin должен:
1) При матче в урле gitlab***/-/pipelines/new и наличие в нем квери параметров активируется плагин
2) максимально используй апи gitlab (ref=test&var[VERSION]=1.2.0)
2.1) для переключения Run for branch name or tag используй ref 
2.2) для variables используй `var[<name>]` 
3) для inputs используй `input[<name>]` (это как раз новая функциональность коотрая не поддерживается gitlab) 
3.1) после загрузки или переключения branch нужно подождать загрузки inputs
3.2) inputs могут оказаться пустыми, или их не будет, тогда они игнорируются
3.3) параметры могут быть не только строковые но еще и в виду drowdown box

## Часть 2

Пользователь может настроить Chrome Plugin
1) можно создавать несколько профайлов, менять имя, удалять
2) при нажатии apply система берет урл до `/-/` и навигирует на `<repo>/-/pipelines/new` и подставляет квери параметры из профиля, а затем уже отрабатывает основная логика из "часть 1"
3) профиль состоит из строчек каждая сточка имеет названание параметра и его значение и тип (variable, input, branch (может быть незада, но если задан то только один)), которое может задавать пользователь
4) можно переключать view профиля на балк где параметры можно заполнить в query формате 
5) Есть кнопка считать текузение параметры уже заданные на странице pipelines чтобы обновить текущий profile
